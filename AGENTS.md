# AGENTS.md

Guidance for coding agents working in this repository.

## Project Shape

- This is a Go + PocketBase app with an embedded React frontend.
- Backend entrypoint: `cmd/server/main.go`.
- PocketBase migrations live in `migrations/`.
- Frontend app lives in `web/` and uses Vite, React, TanStack Router, TanStack Query, Tailwind, shadcn-style UI components, and PocketBase JS SDK.
- Built frontend files are embedded by `web/dist.go` using `go:embed all:dist`.
- Local PocketBase data lives in `pb_data/`; do not edit or delete it unless explicitly asked.

## Important Commands

Run frontend checks from `web/`:

```sh
pnpm run lint
pnpm run build
```

Run backend checks from repo root:

```sh
go test ./...
go build -trimpath -o server ./cmd/server
```

Run the backend locally:

```sh
go run ./cmd/server serve --http=127.0.0.1:8090
```

Run the frontend dev server:

```sh
cd web
pnpm run dev
```

The frontend PocketBase URL is configured in `web/src/lib/pocketbase.ts` and can be overridden with `VITE_POCKETBASE_URL`.

## Backend Notes

- The Go module is `hoplopthcs`; keep imports consistent with that module name.
- `cmd/server/main.go` registers migrations, JSVM, GitHub update checks, custom record hooks, and static frontend serving.
- Current custom hooks:
  - Public `feelings` submissions are forced to `is_approved=false` and `is_public=true`.
  - Public `rsvps` submissions normalize/dedupe contact and default to `is_approved=false`.
  - Approved `rsvps` sync into `members`, including class relation and thumb copy.
- When changing collections, add a new migration instead of editing already-applied migrations unless the user explicitly wants a reset.
- Be careful with file fields. RSVP thumb sync copies files through PocketBase filesystem APIs.

## Frontend Notes

- Routes are file-based under `web/src/routes/`.
- `web/src/routeTree.gen.ts` is generated by TanStack Router; do not hand-edit it unless fixing generated route state after route file changes and build cannot regenerate it.
- Shared data hooks are in `web/src/hooks/`.
- Shared domain types are in `web/src/types/index.ts`.
- PocketBase helpers are in `web/src/lib/pocketbase.ts`.
- Keep UI consistent with the existing reunion visual language unless the user asks for a redesign.
- Prefer existing UI primitives in `web/src/components/ui/` before adding new components.

## Product Context

- The app is a reunion site for "Giao Lộ Khối 9".
- Key public sections: home, members, teachers, gallery, feelings, RSVP.
- Public submissions usually require approval before showing on the site.
- Do not show private contact information on public cards unless the user explicitly requests it.

## Working Rules

- Use `rg`/`rg --files` for searches.
- Use `apply_patch` for manual file edits.
- Do not run destructive commands such as `git reset --hard`, `git checkout --`, or deleting data without explicit user approval.
- The worktree may contain user changes. Do not revert changes you did not make.
- Keep changes scoped to the request; avoid unrelated refactors.
- After code changes, run the relevant checks. For frontend changes, run `pnpm run lint` and `pnpm run build`. For backend or migration changes, also run `go test ./...`.
